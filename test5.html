✅ 推薦作法：使用 GitHub Releases — 免費、穩定、支援版本記錄。

1️⃣ 建立 GitHub 公開倉庫，上傳檔案至 Releases 頁面。
2️⃣ 複製下載直鏈 (通常格式為 https://github.com/帳號/倉庫/releases/download/版本/檔名)。
3️⃣ 修改下方對應的 downloadUrl 即可。

🔁 若使用 Google Drive：取得檔案ID後，連結格式 → https://drive.google.com/uc?export=download&id=檔案ID

⚡ 本頁面已預留動態更新函數，於瀏覽器控制台輸入：
updateDownloadLink(索引, "新網址", "新檔名")
即可即時更新，不需重新整理。

※ 目前範例連結皆為佔位符，請務必替換後再提供給使用者。
